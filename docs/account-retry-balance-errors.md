# 切号与余额不足记录

在系统和分组切号开关均启用时，每个可选账号只尝试一次。上游错误默认继续换号，包括上游账号余额不足、认证异常、未知错误，以及已输出部分内容后的流中断。明确的参数错误、输入超长、内容限制、用户取消或整个请求超时停止。全部账号失败时返回最后一次尝试的错误。

用户在本站余额不足，包括实际费用预检不足，仍在原检查处直接结束，不发起上游请求、不重试。客户端继续收到原状态码和提示。无法获取价格的预检拦截不算余额不足。

不增加页签。错误请求只保存同一用户每次余额增加后的首次余额不足记录；后续重复记录不写入。不同 API Key、分组和网关实例共用同一规则。余额扣减、日志清理、服务重启不重置，充值、管理员加款等余额增加会重置。记录继续排除在 SLA 统计之外。

迁移 260 使用数据库原子判定首次，异步入库不阻塞请求检查；重复插入正常返回，不触发队列重试。入库时间晚于充值的旧请求仍归入原期间。规则对部署后的新记录生效，不改写已有历史错误。

验证包含各协议流中断与部分输出切号、未知上游 400、本站余额停止、自定义预检文案、并发首条去重、余额增加重置、日志清理后不重置。数据库测试使用独立本地库，通过 `OPS_SLA_TEST_DSN` 指定，测试结束删除独立 schema。
