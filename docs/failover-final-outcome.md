# 切号后的错误与结果

开启系统和分组切号后，Anthropic 自动透传会先识别完整流式事件。可重试的错误只记入后台，失败账号的消息开头也先暂存；切号成功时客户端只收到后续账号的正常结果。全部失败、不可重试的参数错误或请求取消时结束尝试。已经发送正文或工具内容后遇到明确错误，不重复输出已有内容。

错误详情显示实际账号尝试顺序、每次结果、状态码、耗时与错误信息，以及最终账号和最终成功／失败／取消状态。旧记录缺少链路时明确提示不完整，不推断历史成功。

后台记账只复制切号标记，沿用已有按账号区分的用量编号，避免两个账号使用相同编号发生冲突。不回填历史用量。

测试使用本地模拟响应，覆盖多账号连续失败后成功、全部失败的最终错误、单行／多行／无结尾空行的错误事件、心跳、参数错误、已输出内容、请求取消、链路持久化与详情展示。
