# 用户作品管理

现有用户后台增加“我的作品”菜单，地址 `/media-library`，沿用后台布局、登录和菜单设置。页面内不重复标题。图片与视频按时间从新到旧展示，滚动到底部自动加载下一页，切换类型后从该类型的第一页加载。

预览直接使用全屏遮罩，无模态框外壳。左右箭头切换作品，底部支持缩放、顺时针旋转和重置；放大图片后可拖动查看。支持键盘左右键、Esc 关闭，关闭后焦点回到原卡片。视频保留播放控件。

删除前需要确认。清空会先获取全部作品，包含尚未滚动加载的作品，不受图片/视频筛选影响；获取失败时不会开始删除。每批 10 个，顺序调用，弹窗显示进度，失败项保留并可重试。清空期间不可切换页面，刷新或关闭浏览器会中断后续批次，重新打开后可继续清理。

## 接口与归属

- `GET /api/v1/media-files?after=...&kind=image`：使用用户登录身份，按时间和编号分页，每页最多 50 条；`kind` 可省略，或为 `image` / `video`。只展示本人已完成且媒体服务上仍存在的图片、视频。
- `POST /api/v1/media-files/delete`：`{"ids":["mf..."]}`，每次 1–50 个。媒体服务实际删除成功后，主站记录删除状态，重复调用可安全重试。
- 媒体服务新增 `/management/files/status` 和 `/management/files/delete`，仅使用已有管理凭据访问，并再次核对文件归属。保留时间来自媒体服务当前设置。
- 删除会移除文件及其旁边的元数据文件，清除原始响应中的图片内容。其余文件仍可下载；Gemini 结果按剩余文件重新组成，不保留已删除文件的原始说明文字。

## 本地开发

当前工作区的 `frontend/.env.development.local` 将 Vite 接口代理到 `https://llmfree.work`，端口为 `18149`，关闭模拟登录与媒体预览数据。使用正式前端入口和真实账号登录。生产尚未上线本次接口时，作品接口返回 404；本地页面不会再用模拟作品填充。通知、抽奖接口也指向同一生产站点。

## 验证

页面测试覆盖灯箱、倒计时、确认删除、分页、分批清空、失败保留与重试；后端测试覆盖用户隔离、超过 200 条分页、实际文件删除、重启和旧任务更新后的删除状态。浏览器使用原后台入口和本地模拟数据检查布局，未调用线上生成与删除接口。
