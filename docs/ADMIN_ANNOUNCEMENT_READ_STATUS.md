# 公告已读情况

管理员打开公告的「已读情况」后，顶部可选择「全部」或「已读」。筛选在数据库分页前执行，可与用户搜索、排序、分页同时使用；切换筛选时回到第一页。

分页旁的「已读 N 人」表示这条公告的已读总人数，不随搜索或当前页变化；不包含已删除用户。没有已读用户时显示 0 人。

接口 `GET /api/v1/admin/announcements/:id/read-status` 新增：

- 查询参数 `read_status=all|read`，默认 `all`。
- 分页响应字段 `read_count`，其余分页字段保持原有结构；`total` 表示当前搜索和筛选条件下的用户数。
