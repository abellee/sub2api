# 主站媒体中转

主站负责账号选择、用户归属、下载链接记录和扣费；媒体文件保存在 mediad，不向主站复制，也不在通知后删除。

- 客户端图片/视频生成：`POST /media/...`，持久受理后返回 202 与任务号。
- 查询：`GET /media/tasks/{task_id}`，仅允许任务所有者；扣费和链接记录完成后返回下载链接。
- 用户下载记录：`GET /media/files`，最多返回当前用户最近 200 条已完成记录。
- 单条记录：`GET /media/files/{record_id}`，检查用户归属。
- 下载入口：`GET /media/files/{record_id}/content`，检查用户归属后 307 跳转到中转服务，不传输或保存文件字节。
- 上传和删除不再由主站文件接口提供。

`media_generation_files` 表由迁移 `250_media_generation_files.sql` 创建，保存 user_id、api_key_id、task_id、file_id、download_url、model、content_type、size_bytes、sha256、ready、created_at。用户外键随用户删除清理元数据；不会因此删除远程媒体文件。

通知写入流程：先以任务/文件唯一键保存用户关联的链接元数据（不可见），再运行主站现有扣费，成功后标记 ready。任何失败返回非 2xx，让 mediad 重试。重复通知不重复创建记录，用户/任务归属不能被覆盖。主站不请求媒体字节，也不发送删除文件的 ACK。

视频沿用主站现有视频计费字段；目前仅支持 1–15 秒，超出明确拒绝，不把长视频静默按 15 秒结算。

用户得到的下载链接含不可猜测的文件令牌，效果类似持有链接即可下载。不要公开分享链接、记录查询令牌或把完整链接写入分析日志。中转服务只有收到主站成功通知确认后才开放该下载。

配置、管理员接口与本地测试说明见 ADMIN.md。
